# 为什么当前内部融合版不如之前的后置插件：代码与结果分析

## 1. 结论

当前版的主要问题是：把“冻结底模、受限残差校准”改成了“内部多处注入、主干联合训练、完整轨迹分布监督”，但没有同时完成文本有效性控制、分布与点预测的决策关联以及不同模型内部结构的专门适配。修改幅度和优化难度增加，测试泛化没有稳定改善。不是单纯训练轮数不够，也没有证据把退化归因于反归一化。

这是代码与已完成训练记录的诊断，尚无本轮消融实验能确定各原因贡献的百分比。下面区分已确认的实现差异与需要验证的机制推断。

## 2. “第一版”的三个参照

历史上存在初始后置版、调参后置版、首轮内部融合V2。不能把它们混为一个版本。

### 2.1 当前误差与调参后置版误差直接比较

参照 `GANF_parameter_experiment_20261003/results_180_mean_std.csv` 的三种子独立训练平均预测误差，当前参照完整实验seed2026。表内为36任务的误差相对变化算术平均：正数变差，负数改善。这里采用“误差变化”而非“下降百分比”，以便直接回答比旧版好还是差。

|模型|当前MSE相对旧插件变化|当前MAE相对旧插件变化|
|---|---:|---:|
|SpecTF|+12.95%|+12.44%|
|MM-TSFlib|+13.24%|+5.72%|
|TaTS|+2.72%|+1.45%|
|CFA|−2.10%|−0.19%|
|Aurora|−20.08%|−17.16%|

所以“最新修改整体比第一版差”不能用于全部模型；但对SpecTF、MM-TSFlib和TaTS，这个观察成立。三种子与单种子、训练协议和底模权重存在变化，本表只比较已保存的性能，不是仅改变模块的因果实验。

### 2.2 相对各轮自己的匹配control

以下采用下降百分比，正数改善、负数变差。各轮control并非同一套权重。

|模型|内部V2 MSE下降|当前MSE下降|内部V2 MAE下降|当前MAE下降|
|---|---:|---:|---:|---:|
|SpecTF|−5.16%|−1.06%|−1.48%|−1.63%|
|CFA|−1.21%|+0.55%|−1.57%|−0.89%|
|TaTS|+9.74%|+4.62%|+6.26%|+2.13%|
|MM-TSFlib|−1.39%|−7.60%|+1.61%|−3.08%|
|Aurora|−5.08%|+0.96%|−3.54%|−0.26%|

相较首轮内部V2，当前SpecTF的MSE和CFA两指标相对对照有改善，但问题未解决；TaTS收益缩小、MM-TSFlib进一步退化。不能只挑一个版本作为比较参照。

### 2.3 初始后置版为什么看起来更稳定

初始后置版180任务仅37项启用修正，143项保留原预测；28项两指标改善、9项至少一指标变差。初始版平均下降幅度实际很小：各模型MSE约0.04%～0.30%，MAE约0%～0.18%。它的稳定性部分来自验证集不支持时关闭修正，并非深度融合已经成功。

调参后置版也保留验证启用规则：180项中104项维持原预测。当前版则对全部任务使用内部融合和分布头，没有外部alpha=0回退。两种设计的退化覆盖面不能直接比较。验证集门控不保证测试改善，旧版也有测试退化。

## 3. 已确认的代码变化及其风险

### 3.1 原先隔离风险，现在梯度影响底模

旧 `plugins/semflow/model.py` 从保存的base预测训练残差修正，原预测网络不更新。修正使用 `correction_limit*tanh(mixture_mean)*gain` 限幅；`semflow/run.py::choose_alpha` 仅在验证MSE与MAE都至少改善0.2%时启用，否则alpha=0。调参后置版去掉0.2%门槛，但仍要求两项验证指标改善。

当前 `internal_semflow_full_lab/native.py::_install_layers` 在encoder层、部分模型decoder层之后注入特征；`core.py::finish` 保留主干隐藏特征的梯度。点损失、NLL和CRPS都会通过共享上下文或内部融合影响主干。模型会共同适应新分支，不能认为“插件关闭后自动等于原版”；即使输出修正头置零，主干也已经变化。

**推断：**原版已有效的表示可能被辅助任务改变，弱文本影响可以沿多层传播，尤其MM-TSFlib同时修改encoder和decoder。这是负迁移风险，不是通过当前结果就已证明了每层发生负迁移。

### 3.2 位置头不直接使用flow的分布形状

当前预测为：

```text
context = context_network(numeric_states + pooled_native_hidden + event_evidence)
draws = flow.samples(context)
correction = decision(context)
prediction = native_prediction + local_scale * correction
```

`draws.mean()`用于样本居中与密度计算，却不进入最终`correction`。保持context与native固定时，改变flow层参数不会改变点预测；点预测损失对flow专属参数的直接梯度为零。NLL/CRPS通过共享context间接影响位置头与主干，CRPS也会训练位置头，但分布形状没有被明确转换成MSE/MAE最优决策。

**已确认的设计缺口：**用户希望“学习未来分布，再分析分布作预测”；当前实现变成位置预测与分布形状共同训练、位置预测独立输出。它有分布建模，但不足以证明分布建模产生点预测收益。

也不能简单退回有限16样本的均值/中位数；那会引入近似误差。后续应在统一标准化尺度上，从预测分布显式最小化点预测风险，例如 `E[(a-Y)^2+0.5|a-Y|]`，并与直接位置头作验证集对照。

### 3.3 固定损失系数并不代表辅助目标很弱

实际损失：`MSE+0.5MAE+0.03NLL+0.02CRPS+0.001regularity`。代码detach了NLL目标中的点预测，避免直接拉动预测位置，但context未detach，所以分布监督仍然影响底模。源码“Residual location also has gradients into the native prediction”注释与当前detach实现不一致，应修正文档；这不是当前执行逻辑中的直接梯度证据。

Agriculture/6插件训练记录最后一轮的batch平均损失示例：

|模型|点损失|加权NLL+CRPS|相对点损失|
|---|---:|---:|---:|
|SpecTF|0.09842|0.04369|约44%|
|CFA|0.13925|0.05374|约39%|
|TaTS|0.05671|0.02659|约47%|
|MM-TSFlib|0.08755|0.04592|约52%|
|Aurora|0.05035|0.03153|约63%|

这些只是损失数值比例，不等同于梯度范数比例；NLL还有分布尺度相关的常数。因此不能据此直接证明梯度冲突。但它清楚说明“系数只有0.03/0.02所以很保守”没有依据。是否竞争，需要测共享层梯度范数和夹角，并做辅助梯度隔离消融。

### 3.4 文本存在门控不能保证文本有效

`EventMemory` 有相关性sigmoid gate，但没有旧版的语义效用teacher/BCE；`InternalFusion` 最后只使用 `memory.valid.any()` 判断文本是否存在。文本只要存在，即使与目标无关、重复、缺少领域含义，也会进入融合。乘 `tanh(evidence)` 不保证无效文本的evidence为零，因为投影和注意力都可学习非零值。

旧调参实验的已保存holdout消融：真实文本综合变化−1.80%，无文本−2.19%，窗口内打乱−1.81%（这里负数表示改善）。真实文本并未优于无文本，也未明显优于打乱。这个结果不能自动移植为当前版的结论，但它说明此前没有证据证明文本带来了额外收益；据此扩大文本内部影响缺少支持。

后续需要文本增量效用对照与置信校准，而不是只把相关性门控权重放大。

### 3.5 通用融合没有充分适配SpecTF和CFA

SpecTF：`InternalFusion(complex_features=True)` 将复数实部/虚部拼接，用通用实数MLP生成两部分增量，在历史频域与未来频域两处注入。没有显式频率条件、相位约束或频带可靠性约束。保持张量可运行和复数类型，不等于保持原生频域建模的归纳偏置。历史事件带时间位置，但频域query没有由本插件专门编码频率坐标。

CFA：当前保留原生文本adapter，再在每个encoder层输出加通用事件融合；两条文本路径可能重复解释同一语义，缺少冗余抑制。`tokens.mean(1)` 又把原生hidden汇成单个摘要用于分布context，可能弱化patch/变量结构信息。

这些都是已确认的结构差异；“破坏相位造成SpecTF退化”“两路冗余造成CFA退化”仍属于待验证假设。CFA当前整体退化较小，不能把它写成已经失败得和MM-TSFlib一样严重。

### 3.6 修正没有旧版的幅度限制

当前 `decision` 是无界线性输出，最终修正乘局部历史标准差；`strength` 用sigmoid但初始值0对应0.5，仅靠up零初始化维持初始恒等。训练以后没有限制特征增量的相对范数。regularity=0.001只约束当前模型输出与其自身native输出的距离，不约束底模相对保存原版的漂移。

**推断：**少数高波动或分布变化任务可能产生过大修正，且主干漂移不受此正则控制。并非观察到大误差就能断定一定是输出修正过大，还需记录内部native、correction和最终prediction三者。

## 4. 训练记录实际揭示什么

|模型|原版训练轮数中位数|插件训练轮数中位数|插件最佳轮≤5的任务|验证两项改善但测试至少一项变差|
|---|---:|---:|---:|---:|
|SpecTF|155|41.5|6/36|9/19|
|CFA|37.5|33|12/36|7/13|
|TaTS|31.5|30|20/36|7/18|
|MM-TSFlib|39|38|10/36|6/12|
|Aurora|30.5|30.5|18/36|6/10|

最佳轮≤5意味着最终恢复的权重来自早期，不代表仅训练了5轮。当前至少30轮、连续25轮验证综合分数未明显改善后停止。全部360训练满足这个规则，但它不能证明训练损失收敛到最佳解，更不能保证测试集泛化。

SpecTF原版在精简实验的部分60轮预算里未充分训练；补足原版训练后，之前看起来明显的插件优势减弱。完整实验还加入了原先没覆盖的领域和步长。当前版与精简版 `core.py` 完全相同，并不是完整实验时又换了一套更差的模块。

九领域合并五模型的平均下降百分比，Agriculture为MSE+13.55%、MAE+7.84%，Health为+6.77%、+1.37%；Environment为−9.97%、−6.39%，Energy为−8.57%、−3.75%。精简实验只看Agriculture/12与Economy/10，不能代表这个完整分布。

严重退化任务包括MM-TSFlib/Energy/12：MSE增加62.81%、MAE增加31.01%；MM-TSFlib/Health/24：增加62.78%、29.28%；SpecTF/Traffic/6：增加53.94%、44.57%。应先定位这些任务，而不是再次对180项统一放大权重。

## 5. 数据、归一化与协议混杂

- 当前所有任务共享Readgpt来源的canonical数据；训练与测试按时间划分；全局归一化统计只取训练段。
- 当前原版与插件逐项核验相同test origins和target数组，MSE/MAE按同一个训练统计标准化尺度计算。没有对插件单独反归一化，因而本轮插件相对control的退化不能解释为“双方用了不同反归一化”。局部scale参与模块内部修正，但不是评价尺度变更。
- 旧后置版冻结旧底模；当前冷启动重训并保持本轮同设置control。Aurora还采用本地预训练模型末两层及预测头微调，区别于历史作者运行路径。因此当前对历史底模的增益很大，也不能全部算插件贡献。
- 之前AutoDL V3方案计划继承已训练control权重、主干lr2e-5、两种插件权重验证选择；迁移实验室后实际方案改为冷启动、主干lr1e-4、固定插件权重。应以 `outputs_full/PLAN.json` 与每任务run_config为准，不能拿V3方案文档当成当前已执行设置。
- 旧调参后置版有三种子平均，当前单种子；不能把宏平均小差异当成统计稳定提升。
- Security仅297个时间点，验证31点，12步预测只有20个验证窗口，且大量重叠。完整轨迹flow、事件记忆和主干联合优化容易依赖有限验证样本。Environment长步336的flow和16样本近似也更难可靠估计。这里是样本与结构风险分析，尚无独立时间块实验作因果验证。

## 6. 下一步最小定位实验，不立即再跑全量

保持当前结果与代码不变，先保存私密Git快照。选择SpecTF和MM-TSFlib各三个领域/步长，包含明确退化任务及一个改善任务，以验证集确定方案；测试只作锁定后的确认，不用于挑选赢家。

|对照|要排查的因素|
|---|---|
|匹配的追加训练control|区分额外训练与模块收益|
|仅位置修正，冻结原生底模|验证后置校准是否足够，隔离主干漂移|
|仅内部语义融合，不使用分布辅助目标|定位特征注入本身是否负迁移|
|完整模块，但辅助NLL/CRPS对主干梯度隔离|定位辅助目标是否干扰主干|
|完整模块，真实文本/无文本/打乱文本|确认真实语义的额外作用|

上述是因素定位清单，实际先跑前四组，文本消融只在确有收益的结构上补充，避免又把精简定位变成大规模扫参。比较训练曲线、验证指标、点预测与分布质量、修正幅度、共享层梯度；不承诺所有模型和领域都提升。

确认机制之后，采用小幅模型专门接口：SpecTF用频率条件与幅相受限调制，CFA做原生语义路径与新事件路径的增量/冗余控制；共用事件条件分布思想，不把所有内部张量当同一种token。分布位置与点预测风险要显式关联；以可信文本增量贡献控制融合强度。通过验证再扩大到180项。

## 7. 分析范围与责任

本轮没有修改模型代码、没有启动新的训练。当前明确问题是设计和实验推进：尚未证明语义增益与分布决策收益，就同时扩大了特征融合、主干更新与分布辅助目标，并用两个领域的精简表现推动完整实验。这个推进不足需要纠正，不能归咎于服务器，也不能把满足早停规则当作模型已经优化到应有的最好效果。

支撑文件：初始 `GANF_semflow_results/结果分析.md`、调参 `GANF_parameter_experiment_20261003/参数实验结果分析.md`、内部V2 `comparison_180.json`、当前 `RESULTS.json`、每任务COMPLETED/training记录，以及本目录 `版本退化诊断数据.json`。
