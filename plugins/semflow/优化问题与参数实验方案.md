# 语义条件图流：弱增益原因与参数实验方案

> 2026-10-03。此文是代码与既有结果的诊断及**下一轮方案**，未执行新训练。原始五模型和已完成的两轮结果保持不变。

## 1. 观察到的现象

- 180 个任务中，holdout 门控只启用 37 项；测试集 28 项 MSE/MAE 同时改善，9 项至少一个指标变差，143 项原样输出。五模型平均改善仅约 0.00%–0.32%。
- 所有启用项的 `alpha` 都是 1，其他项都是 0；候选的 0.25、0.5、0.75 从未胜出。单模型微调后，167/180 项最优 epoch 仍为 0。
- 共享模型的最佳 epoch 中位数为 1，36 个领域/步长的 holdout 相对误差中位数约 0.99999，说明共享阶段几乎没有稳定的验证增益。四个领域 Climate、Economy、SocialGood、Traffic 完全没有启用修正。以上是**现象**，不能据此直接判定“文本无效”。

## 2. 代码检查：确定的问题与待验证假设

| 优先级 | 位置与问题 | 对结果的可能影响 | 判断 |
|---|---|---|---|
| 高 | `model.py` 的点预测为 `base + scale × 0.5 × tanh(mean) × sigmoid(correction_logit)/(1+variance)`；`correction_logit=-2`，初始 `sigmoid≈0.119`，且方差进一步缩小修正。 | 有效修正初始上限远小于一个历史标准差；长预测或系统偏差可能根本修不动。 | 代码可确定；幅度是否构成主要瓶颈要量化。 |
| 高 | `coefficients=4` 对所有步长固定，包括 H=192/336；流只对前四个低频 DCT 系数建模。 | 局部峰值、高频波动及不同预测时点的误差难被表达。 | 表达限制可确定；需计算真实残差的前 K 项能量占比。 |
| 高 | `_semantic_evidence()` 最终对所有有效历史时点**均匀平均**，只有每个时点内部的 lag 权重可学。 | 稀疏事件或最近文本可能被长窗口中的旧文本冲淡。 | 代码可确定；需文本置乱、事件窗口消融。 |
| 高 | `run.py` 用未经过最终 `alpha` 门控的五模型平均验证误差选共享 checkpoint，随后每模型才用“两个指标均改善至少 0.2%”选 `alpha`。 | epoch 选择目标与最终发布目标不一致；可能错过对某些模型真正有用的 checkpoint。 | 代码可确定。 |
| 中 | `data.py` 使用冻结 BERT 的 256 token 截断与均值池化；没有领域适配，也没有核验 `fact` 的实际发布时刻。 | 语义可能被模板文本、重复文本或时间错配掩盖。 | 原因是假设；先做数据审计，不直接换编码器。 |
| 中 | `run.py` 将五底模样本混合训练同一图流；输入只有预测轨迹的少量低频系数，没有模型身份。微调 167 项在 epoch 0 最优。 | 不同底模残差机制可能互相抵消；也可能只是样本不足。 | 待比较共享、模型条件化、单模型训练。 |
| 中 | `make_adapter_dataset.py` 把原验证区间前 70% 作为 fit、后 30% 作为 holdout，但相邻窗口目标在边界可重叠；没有 horizon-1 的隔离带。 | holdout 不够独立，估计可能偏乐观；不是目前增益小的直接解释。 | 代码可确定，应先修评估协议。 |
| 中 | `objective()` 中点损失为 MSE+0.2 MAE，NLL 权重 0.03，语义效用权重 0.01；没有强制 joint 条件优于文本打乱条件。 | 图流可能学到数值残差，但没有真正使用文本；不能仅凭门控非零宣称多模态贡献。 | 待消融证实。 |
| 低 | 固定 16 个 Sobol 样本估计方差，并用未校准方差压低修正；`semantic_profile()` 报告的 uncertainty 仍是标准化残差单位。 | 修正和语义显示的幅度可能不准。 | 需覆盖率、NLL 和方差校准检查。 |

当前检查未发现明确的反归一化混用：`make_adapter_dataset.py` 用训练段均值/标准差统一缩放，并验证 `true.npy` 与目标窗口一致。后续仍要抽样核对五底模预测文件的排序和文本时间戳。

## 3. 实验前先做无需训练的诊断

1. **还原完整候选预测**：当前 `run.py` 对 `alpha=0` 只保存最终原样预测，缺少插件未门控的原始预测。下次运行应同时保存原始插件预测、holdout 预测、门控值、方差与每项残差；不应从测试集反推门槛。
2. **残差频谱**：分别计算 K=4/8/16/32 对真实残差的 DCT 能量覆盖率，以及四类步长上的重建 MSE。若 K=4 覆盖率低，先增加表示能力；若已很高，优先查训练和门控。
3. **修正幅度**：记录 `|pred-base|/history_std` 的中位数、95 分位数、与基础误差的比值；同时统计 gate 和方差分布。若修正远小于基础残差，幅度抑制是假设中最强的候选原因。
4. **文本审计**：按领域统计空文本、重复文本、长度、是否带目标数值或未来信息，以及文本时间戳与观测时间戳的关系。
5. **训练过程**：逐组画点损失、NLL、holdout MSE/MAE 和 gate 随 epoch 变化；核对“最佳 epoch=1”来自真实过拟合还是目标不一致。

## 4. 对照与参数实验设计

先固定数据原点、五底模预测、数值标准化与文本缓存。新建独立实验目录，不覆盖已完成结果。按时间顺序切分 fit / selection holdout，并在边界留 `H-1` 个预测原点的隔离带，避免 fit 与 holdout 目标窗口重叠。所有变体只依据 holdout 选择；测试集留到最终配置冻结后统一评估。此前测试结果已被查看，因此下一轮同一测试集的结果应标为**探索性复现**；若要作强结论，需另准备未见的后续时间块或独立数据集。

### A. 先做消融，判断是否真有文本增益

在相同训练预算和随机种子下比较：①基础预测；②仅历史数值+残差图流；③数值+真实文本；④数值+同领域乱序文本；⑤数值+向过去偏移的文本；⑥取消图流、仅学习同等容量的残差点预测头。关键量是③相对②和④的改善，以及 NLL、预测区间覆盖率。若③与④相近，应先修文本对齐或语义目标，暂不扩大参数搜索。

### B. 单因素筛选，不做盲目全网格

| 因素 | 当前值 | 候选值 | 要检验的问题 |
|---|---:|---|---|
| DCT 系数 K | 4 | `min(H,8)`、`min(H,16)`；H≥96 再试 32 | 长步长残差表示是否不足 |
| 修正上限 | 0.5 | 1.0、2.0 | 是否被幅度硬限制 |
| 修正初始化 logit | -2 | -1、0 | 是否因初始梯度太弱 |
| 方差收缩系数 β：`1/(1+β·variance)` | 1 | 0、0.5 | 未校准不确定性是否过度压缩点预测 |
| 语义汇聚 | 均匀 | 仅最近有效文本、可学习时间注意力 | 稀疏事件是否被平均掉 |
| lag | 0/1/2 行 | 0 行、按领域时间单位扩到 4/8 行 | 文本对齐误差 |
| NLL 权重 | 0.03 | 0、0.1 | 分布拟合与点误差是否冲突 |
| 模型条件 | 无 | 共享模型+5 维模型 ID embedding | 五底模残差分布是否冲突 |
| 隐层宽度 | 32 | 64 | 容量是否不足；仅前述因素无效时试 |

先修 checkpoint 选择目标，让它与最终“按模型的 holdout MSE/MAE 改善”一致；再用相同门槛比较参数。`samples=16` 先保持固定，若分布方差的重复估计不稳定，再比较 32/64，避免与表示和幅度因素混淆。学习率先固定 1e-3、最多 30 epoch、耐心 6；若训练曲线显示欠收敛，再单独比较 3e-4/1e-3 和耐心 6/12。**不要把门槛调低后启用数变多当作模型本身变强。**

### C. 运行范围与筛选规则

- 筛选组覆盖九领域各一组：Agriculture/6、Climate/8、Economy/8、Energy/36、Environment/336、Health/24、Security/10、SocialGood/8、Traffic/8；每组都评估五底模。先用 2 个种子，针对 A 的结论选约 8–12 个有针对性的 B 变体。预算约 `9 × (8–12) × 2 = 144–216` 次领域/步长插件训练；冻结的 BERT 缓存复用。具体耗时以一组实测为准。
- 按五底模、九领域宏平均的**相对 MSE 与 MAE**、同时改善的任务数、任一指标退化数共同筛选；报告每项完整原值和变化百分比，不只汇报平均值。高误差领域 Security 不应单凭绝对误差支配总评分。
- 只保留 holdout 上同时改善且在两种种子下方向一致的 1–2 个配置。最后覆盖全部 36 个领域/步长组合，各跑 3 个种子；以均值、离散度和按时间块 bootstrap 的配对置信区间报告结果。测试集一次性评估，另列任何退化任务。

## 5. 决策条件

若真实文本显著优于乱序文本、DCT 覆盖率和修正幅度问题得到改善，且九领域全量复现中五模型宏平均 MSE/MAE 均下降、退化案例减少，才保留新插件。若文本不优于乱序文本，就先处理文本时间对齐与训练目标；若仅点预测头有效，应说明图流对误差下降没有提供已验证的额外价值。不能承诺全部 180 项同时改善。
